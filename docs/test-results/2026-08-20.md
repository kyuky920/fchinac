## 로컬 DB 통합 검증

합성 회원과 합성 관리자를 사용해 다음 흐름을 확인했다.

1. 가입 신청 시 `pending/member`와 필수 동의 저장
2. 관리자 승인 시 `active` 전환과 감사 로그 생성
3. 비밀번호 재설정 링크 발급과 30분 유효 토큰 생성
4. 새 bcrypt 비밀번호 저장, 토큰 소진, 기존 세션 폐기
5. 회원 차단 시 모든 활성 세션 폐기
6. 관리자 자기 계정 차단 거절

검증 종료 후 합성 계정 2개와 연결 레코드를 제거했고 기존 백업 회원 수 382명을
유지했다. 운영 서버와 운영 DB에는 접근하지 않았다.
