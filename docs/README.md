# 개발 문서 안내

이 디렉터리는 안디옥성경사이버선교회 홈페이지 갱신 프로젝트의 기준 문서를
관리한다. 운영 서버의 정보나 비밀번호, DB 덤프, 회원 개인정보는 문서와 Git에
포함하지 않는다.

| [요구사항 명세서](requirements-specification.md) | 기능·비기능 요구사항, 완료 상태와 인수 조건 |

## 관리 원칙

1. 기능을 추가하거나 범위를 바꿀 때 요구사항 ID와 상태를 먼저 갱신한다.
2. DB, 인증, 배포 구조가 바뀌면 시스템·DB 설계서를 함께 갱신한다.
3. 구현을 완료할 때 해당 요구사항의 인수 조건을 테스트 계획에 반영한다.
4. 결정되지 않은 내용은 구현 완료로 표시하지 않고 `검토 필요`로 남긴다.
5. 운영 자격증명과 개인정보는 문서에 기록하지 않는다.
