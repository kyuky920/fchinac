# 테스트 케이스 명세서

## 1. 공통 정보

| 항목 | 내용 |
|---|---|
| 대상 | 안디옥성경사이버선교회 홈페이지 갱신 애플리케이션 |
| 기본 환경 | Next.js standalone, 로컬 MariaDB `fchinac_dev` |
| 기준 브라우저 | Chrome·Safari 최신 버전, 모바일 390px 이상 |
| 자동 테스트 | `pnpm test` |
| 테스트 데이터 | `example.invalid` 이메일을 사용하는 합성 계정 |
| 금지 사항 | 운영 서버·운영 DB에서 자동 테스트 실행 금지 |

우선순위는 `P0` 출시 필수, `P1` 핵심 회귀, `P2` 보조 기능을 의미한다.

## 2. 회원가입 TC

### TC-MEM-001 정상 가입 신청

- 관련 요구사항: MEM-002
- 우선순위: P0
- 사전 조건: 동일 아이디와 이메일이 존재하지 않고 선택 언어가 활성 상태다.
- 입력: 허용 문자 아이디, 유효한 이메일, 표시 이름, 선택 거주 국가·성별, 영문·숫자를 포함한 10자 이상 비밀번호, 필수 동의와 만 14세 이상 확인
- 절차:
  1. `/{locale}/membership#register`에 접속한다.
  2. 유효한 정보를 입력하고 가입 신청을 제출한다.
  3. DB의 회원, 프로필, 동의, 역할, 감사 로그를 확인한다.
- 기대 결과:
  - 완료 안내가 표시된다.
  - `users.status='pending'`, 역할은 `member`다.
  - 이메일은 소문자로 정규화된다.
  - 비밀번호는 bcrypt 해시이며 평문이 저장되지 않는다.
  - 약관·개인정보 동의와 `self_registered` 로그가 남는다.
  - 선택 입력한 거주 국가와 성별, 동의 문서 버전이 저장된다.
- 자동화: 입력 정책 단위 테스트 + 로컬 통합 테스트

## 3. 로그인·세션 TC

### TC-AUTH-001 승인 대기 회원 로그인

- 관련 요구사항: MEM-003
- 우선순위: P0
- 사전 조건: 올바른 비밀번호의 `pending` 회원
- 절차: 아이디와 비밀번호로 로그인한다.
- 기대 결과: 승인 대기 안내가 표시되고 세션이 생성되지 않는다.
- 자동화: 로컬 통합 테스트 완료

### TC-AUTH-002 로그인 실패 제한

- 관련 요구사항: NFR-003
- 우선순위: P0
- 절차: 같은 식별자로 15분 내 틀린 비밀번호를 5회 이상 제출한다.
- 기대 결과: 추가 로그인 시도가 제한되고 성공 여부와 무관하게 평문 식별자는 로그에 남지 않는다.
- 자동화: DB 통합 테스트 예정

### TC-AUTH-003 활성 회원 로그인

- 관련 요구사항: MEM-001, MEM-003
- 우선순위: P0
- 절차: 승인된 회원의 올바른 자격증명으로 로그인한다.
- 기대 결과: HttpOnly 세션 쿠키가 발급되고 최근 로그인 시간이 갱신된다.
- 자동화: 로컬 통합 테스트 완료

### TC-AUTH-004 차단 회원 세션 폐기

- 관련 요구사항: MEM-007
- 우선순위: P0
- 사전 조건: 활성 세션이 있는 회원
- 절차: 관리자가 회원 상태를 `blocked`로 변경한다.
- 기대 결과: 모든 미폐기 세션에 `revoked_at`이 기록되고 이후 요청은 비회원으로 처리된다.
- 자동화: 로컬 통합 테스트 완료

### TC-AUTH-005~007 레거시 비밀번호 호환과 자동 전환

- 관련 요구사항: MEM-001, NFR-001
- 우선순위: P0
- 절차: MySQL 4.1 해시를 가진 활성 회원이 기존 비밀번호로 로그인한다.
- 기대 결과: 로그인과 세션 발급이 성공하고 해당 계정의 비밀번호가 bcrypt cost 12로 전환된다.
- 자동화: `tests/unit/password.test.ts` + 로컬 관리자 로그인 smoke test

- 기대 결과: 목록에서는 로그인 화면으로 이동하고, 직접 API 요청은 파일을 노출하지 않고 `401`을 반환한다.
- 자동화: 로컬 HTTP smoke test

### TC-BBS-009 로그인 회원 다운로드

- 관련 요구사항: BBS-002, BBS-008
- 우선순위: P0
- 절차: 다운로드 권한이 있는 승인 회원으로 로그인한 뒤 목록의 다운로드를 선택한다.
- 기대 결과: 원본 파일명으로 파일이 내려받아지고 다운로드 횟수가 1 증가한다.
- 자동화: DB 통합 테스트 보강 예정

## 9. 관리자 콘텐츠 운영 TC

### TC-ADMIN-CONTENT-001 공통 관리자 메뉴

- 관련 요구사항: ADM-002, ADM-003
- 우선순위: P0
- 절차: 관리자 로그인 후 대시보드에서 게시물, 게시판, 강의, 회원, 언어, 변경 이력으로 이동한다.
- 기대 결과: 모든 화면이 같은 관리자 메뉴를 표시하고 정상 렌더링된다. 일반 회원은 접근할 수 없다.
- 자동화: 로컬 브라우저 smoke test 완료

### TC-ADMIN-CONTENT-002 게시물·첨부파일 관리

- 관련 요구사항: BBS-004, BBS-005
- 우선순위: P0
- 절차: 게시물 상태·공지 여부를 변경하고 허용 파일을 업로드한 뒤 삭제한다.
- 기대 결과: 게시물 목록과 사용자 화면에 상태가 반영되고, 파일은 내부 키로 저장되며 변경 이력이 남는다. 실행 파일·초과 크기는 거절된다.
- 자동화: 프로덕션 빌드 및 로컬 통합 테스트, 업로드 경계값 자동화 보강 예정

### TC-ADMIN-CONTENT-003 게시판 역할 권한

- 관련 요구사항: BBS-002, BBS-006
- 우선순위: P0
- 절차: 역할별 목록·읽기·작성·댓글·업로드·다운로드·관리 권한을 변경한다.
- 기대 결과: 설정이 저장되고 공개 목록·다운로드 API에서 같은 권한을 사용한다.
- 자동화: 로컬 통합 테스트 보강 예정

### TC-ADMIN-LECTURE-001 강의 DB 연동

- 관련 요구사항: WEB-005, ADM-004
- 우선순위: P0
- 절차: 관리 화면에서 과목의 재생목록과 차시 노출·재생 여부를 변경하고 기존 과목 URL을 연다.
- 기대 결과: URL은 유지되고 변경된 과목명·차시·YouTube 플레이어가 반영된다.
- 자동화: 분류 6개·과목 48개·차시 686개 DB 무결성 검사 + 로컬 브라우저 smoke test 완료

### TC-ADMIN-AUDIT-001 변경 이력

- 관련 요구사항: ADM-005
- 우선순위: P1
- 절차: 콘텐츠 설정 변경 후 변경 이력 화면을 연다.
- 기대 결과: 관리자, 대상 종류·키, 작업, 시간이 최신순으로 표시된다.
- 자동화: 로컬 브라우저 smoke test 완료

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

CI는 모든 PR과 `main` 반영 시 위 검사를 실행한다. 실패한 TC는 요구사항 ID,
재현 절차, 기대·실제 결과, 수정 커밋을 이슈에 기록한다. DB 통합 테스트는 운영
DB가 아닌 CI MariaDB 서비스에서만 자동 실행하도록 후속 보강한다.
