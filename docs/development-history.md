# 개발 이력

기준일: 2026-09-20

## 단계별 요약

### 1. 레거시 분석과 로컬 재구성

- 기존 PHP/Gnuboard 백업을 로컬에서만 분석했다.
- 회원 382명, 게시판 9개, 게시물 50건, 첨부파일 42건을 확인했다.
- 부모 게시물이 있는 첨부파일 38건을 신규 구조로 이전했다.
- 기존 운영 서버를 변경하지 않는 원칙을 유지했다.

### 2. Next.js MVP

- Next.js App Router와 MariaDB 기반 앱을 구축했다.
- 기존 UI를 참고한 홈, 소개, 연혁, 교수, 가입안내, 강의, 자료 화면을 제작했다.
- 레거시 회원 로그인, DB 세션, 역할 기반 권한과 게시판을 구현했다.
- 신규 회원가입과 관리자 승인 흐름을 구현했다.

### 3. 관리자 기능

- 대시보드, 회원, 게시물·첨부파일, 게시판 권한, 강의, 언어, 감사 이력을 구현했다.
- 6개 강의 분류, 48개 과목, 686개 차시를 DB로 관리한다.
- 언어·번역을 관리자 화면과 JSON 일괄 작업으로 관리한다.

### 4. 호스팅 검토와 iwinv 이전

- Cafe24 일반 호스팅과 AI Space를 검토·시험했으나 지속 운영 제약으로 사용하지 않았다.
- iwinv VPS를 스테이징으로 선택했다.
- Ubuntu, Nginx, MariaDB, Node.js, systemd, UFW, Fail2ban과 백업 타이머를 구성했다.
- 로컬 빌드한 standalone 산출물만 서버에 배포하는 릴리스 구조를 적용했다.

### 5. 콘텐츠와 다국어 보정

- 기존 10개 언어에 아랍어, 페르시아어, 네팔어, 태국어, 베트남어를 추가했다.
- 아랍어·페르시아어 RTL과 전체 비한국어 언어의 영어 fallback을 적용했다.
- Agreement, 회장명, 연혁, 연락처와 Family Sites를 사용자 요청에 맞게 갱신했다.
- 공지사항을 홈페이지로 옮기고 가입안내에 회원가입 폼을 통합했다.

### 6. 강의록 게시판

- 동영상 강의와 서적과 자료 사이에 다국어 강의록 메뉴를 추가했다.
- 강의록 목록과 본문은 공개하고 첨부파일은 로그인 회원에게만 제공한다.
- 강의록 게시물·첨부파일의 생성과 관리는 관리자 역할로 제한했다.
